# Internshala Internship Search Clone

A ReactJS-based clone of the Internshala Internship Search Page built as part of the SDE (Web) Internship assignment.

## 🚀 Features

- Internship listing page
- Frontend-only filtering
- Filter internships by:
  - Profile
  - Location
  - Duration
  - Stipend
- Responsive UI
- Internshala-inspired design
- Reusable React components
- Clean and modular code structure

---

## 🛠 Tech Stack

- ReactJS
- CSS3
- Axios
